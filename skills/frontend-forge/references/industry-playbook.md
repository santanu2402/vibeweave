# Industry Playbook

The *safe* starting point per product type — then make one deliberate move away from it.
"Fresh move" suggests where that move might come from. Style numbers refer to
[styles.md](styles.md).

| Product type | Safe direction | Type mood | Palette mood | Fresh move | Avoid |
|---|---|---|---|---|---|
| B2B SaaS (general) | Swiss (1) + Bento (11) | precise grotesk | neutral + one confident accent | live product demo as hero; editorial case-study pages | purple gradient, 3 icon cards, fake logos |
| Developer tools / API | Dark Premium (13), Terminal (16) | mono accents + grotesk | tinted dark, syntax colors | interactive code playground hero; light mode as default for contrast | green-on-black only, gimmick typing |

## Quick heuristics

- **Trust-critical** (money, health, legal, government): contrast, clarity and calm beat novelty.
  Put boldness into photography or typography, not into motion or color.
- **Attention-critical** (events, fashion, music, launches): be loud on purpose; boldness
  is the product.
- **Use-critical** (dashboards, tools): density, speed, keyboard support. Decoration costs money here.
- **Desire-critical** (luxury, travel, food): imagery and space; let the photograph sell.
- When unsure between two directions, pick the one the *competitors don't use*.
